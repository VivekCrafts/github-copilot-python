# GitHub Copilot Instructions for Sudoku Project

## Project Overview
This is a Flask-based Sudoku web application. The application allows users to play Sudoku puzzles with different difficulty levels, timers, hints, answer validation, and leaderboard tracking.

## Coding Guidelines

### Python Style
- Follow PEP 8 coding standards.
- Use meaningful variable and function names.
- Keep functions small and focused on a single responsibility.
- Add comments for complex logic.
- Handle errors using appropriate exception handling.

### JavaScript Style
- Use clean and readable JavaScript.
- Use descriptive names for variables and functions.
- Avoid duplicate code.
- Add comments for important game logic.

## Project Constraints
- Maintain Flask architecture.
- Do not introduce unnecessary dependencies.
- Preserve existing functionality when adding new features.
- Ensure the application remains responsive and accessible.

## Copilot Instructions
When generating code:
- Explain the approach before writing complex code.
- Follow existing project patterns.
- Prioritize readability and maintainability.
- Consider edge cases and error handling.
- Suggest improvements when refactoring legacy code.

## Documentation Guidelines
- Add comments explaining important logic.
- Keep documentation updated when features change.
- Use descriptive names for files and functions.

## Testing Guidelines
Before completing changes:
- Test all Sudoku difficulty levels.
- Verify timer functionality.
- Verify leaderboard updates.
- Verify hints and validation features.
